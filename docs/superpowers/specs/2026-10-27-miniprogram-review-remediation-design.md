# 萌芽护航小程序审核问题修复方案

日期：2026-10-27

状态：待用户审阅；尚未开始修改产品代码。

## 目标和已确认信息

修复本次审核指出的两项问题：登录环节缺少可阅读的协议及事前同意，以及个人主体小程序提供视频服务。

- 小程序对外名称：萌芽护航。
- 运营者对外名称：萌芽护航团队。此称谓不代表已核验平台登记主体；提审前应与后台登记信息核对。
- 隐私联系邮箱：134224553553@qq.com。
- 用户指定的公众号文章：https://mp.weixin.qq.com/s/ZZo7Wlyjx-vHjOS6aVvFEw 。
- 用户选择的方向：用户点击链接后打开公众号内容，在公众号页面播放视频。

当前直接读取该文章收到微信访问验证页面；文章标题、包含的视频及小程序真机跳转尚未验证。HTTP 200 不作为文章内容可用或跳转成功的证据。

## 采用的路径及替代方案

采用现有个人主体和 Taro 小程序：补齐协议及授权流程，将小程序内视频服务改为公众号原文入口，复用现有 UI、反馈抽象和文章能力。

另一条路径是使用具备相应类目资质的主体保留小程序内视频播放，涉及主体、资质和审核范围变更。当前用户提出的是公众号跳转，因此本次按该方向设计。

## 修复一：协议与授权

1. 新增并注册《用户服务协议》《隐私政策》原生页面，复用 Organic 组件和主题。无需登录、无需同意即可阅读；启动时的认证跳转不得阻断这两个页面。
2. 登录页保留默认未勾选的同意框，覆盖验证码发送、验证码登录、密码登录、微信登录及手机号授权。用户未同意时，既不调用对应后台接口，也不触发手机号授权组件。不能仅在授权结果回调中拦截。
3. 对实际使用的微信隐私接口，接入微信官方隐私授权流程。用户取消或拒绝时结束操作，不提交手机号或创建对应登录请求；自建协议勾选不替代微信记录的隐私授权。
4. 在“我的”提供两个协议的长期入口，并统一登录页和“关于我们”的产品名称。
5. 协议依据实际实现描述手机号、微信登录标识、用户主动填写的宝宝资料、生长及预约记录等信息的目的、处理方式和用途；列明联系、删除申请、监护人责任和当前实际使用的第三方服务。不编造主体资质、保存期限、服务器所在地或安全承诺。
6. 微信后台《小程序用户隐私保护指引》由账号管理员按实际处理内容填写，并与代码核对。这部分需要后台操作和验证，不视为代码构建成功即已完成。

本次不改造共享的 App 登录接口。若后续决定增加服务端同意记录，应另行明确协议版本及兼容范围，并同步模型、迁移和序列化。

## 修复二：公众号内容入口

1. 小程序课堂保留原有图文能力，增加一个明确标注“在公众号查看”的内容入口，目标为用户提供的文章链接。文章内容未读到前，入口使用中性名称，不擅自填写文章标题或声称包含某项视频。
2. 移除独立视频分类、视频搜索与列表请求、小程序播放器及其页面注册；首页等关联入口同步调整。直接访问旧视频详情路径不能继续播放。
3. 点击使用微信官方 `wx.openOfficialAccountArticle`。链接在点击前已就绪，调用置于用户点击处理内，避免先异步取链接再失去点击条件。最低基础库要求为 3.4.8。
4. 微信可能显示确认界面；不承诺自动播放。用户取消不报播放故障；接口不支持、链接失效和调用失败给出明确提示，不回退到小程序内视频播放。
5. 现有其他素材没有提供对应文章链接，不能全部改指向这一篇文章。后续增加公众号入口时，每个入口须配置真实对应的已发表文章；可复用已有文章 `sourceUrl`，不将公众号文章地址混写进视频播放地址。
6. 功能限制落实到提交的小程序代码，不依赖后台开关临时隐藏。后台视频接口与其他客户端的用途不在本次修改范围内。

公众号文章跳转具备技术接口，不代表微信已认定调整后的业务符合个人主体类目。提审说明应准确描述实际变化，最终结论以平台复审为准。

## 主要影响范围

- 小程序：应用页面注册与启动认证处理；登录页；新增协议页面；个人页；课堂及首页关联入口；公众号文章打开封装和相关测试。
- 后端和数据库：采用本方案无需更改视频数据、素材同步或共享认证接口。
- 平台配置：核对基础库版本、用户隐私保护指引和提审服务内容说明。

## 验证与交付

按功能分两个修复提交：协议与授权；公众号原文入口及移除内置播放。

采用 TDD 验证实际行为：

- 未同意时发送验证码、登录和手机号授权均不能开始；同意后的正常路径、拒绝和失败路径均有明确结果。
- 未登录可打开两份协议，返回后不自动勾选；“我的”可再次阅读。
- 点击公众号入口时调用官方文章接口，准确传入本篇链接；取消、不支持与失败分开处理。
- 启用旧视频开关或配置请求失败，都不会恢复小程序视频列表、播放请求或播放器。

工程验收：小程序相关行为测试、类型检查、代码检查及微信小程序构建；检查生成包页面与入口。真机验收使用清除授权状态后的账号，完成协议阅读、拒绝/同意、公众号跳转、视频播放和返回。发布或审核通过只在取得实际结果后报告。
